核心功能

专为开发者打造，每一个细节都经过打磨。

⚡

即时转换

选中任意时间戳文本，按下 F9，结果立刻出现在光标旁边。

🔍

智能检测

自动识别秒级（10位）和毫秒级（13位）时间戳，毫秒精确显示 .SSS。

📋

点击复制

点击转换结果即可复制到剪贴板，原始剪贴板内容自动恢复。

🌍

18 个时区

从 UTC 到 Auckland，在托盘菜单中一键切换显示时区。

📌

单条/多条模式

单条模式即用即走，多条模式可收集多个时间戳对比查看。

⌨️

自定义热键

预设 F7/F8/F9/Ctrl+Shift+T，也支持录制任意组合键。

三步上手

不需要配置，开箱即用。

1

下载运行

下载 exe 双击运行，Sundial 自动常驻系统托盘区域。

2

选中 + 按键

在任意应用中选中时间戳文本，按下 F9（默认热键）。

3

查看结果

转换后的时间弹窗出现在光标旁，点击即可复制。6 秒后自动消失。
